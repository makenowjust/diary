## Uiua

Uiuaというプログラミング言語がある。

<https://www.uiua.org>

APLとかと同じく配列指向・スタックベースのプログラミング言語。
Claude Codeに[makenowjust/quine](https://github.com/makenowjust/quine)リポジトリを見せて、追加したら面白そうなプログラミング言語は、と訊いたら提案された。
まあこの手の言語は面白いことが多いのでやっておいて損はない。

Quineはこんな感じ。

```
"&p⟜&s"
&p⟜&s
```

<https://github.com/makenowjust/quine/blob/3b904d51bbc909c7caf641a538904e6802a5eedb/quine.ua>

`&p` が出力、`&s` がpretty print付きの改行で、 `⟜` が現在の値を複製して関数を呼び出すやつ。
まあ大体こうなるって構造になった気がする。

インストールは `cargo install uiua` だった。
ウィンドウも出そうと思えば出せたりするのでビルドが面倒っぽい。
実行は以下。

```
uiua run quine.ua | diff quine.ua -
```

というわけで323言語目でした。
